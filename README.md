# Providercheck

## Deutsch

Clean-Room-Paket für eine **read-only**-Erstprüfung lokaler AI-Coding-Tools
(Token-Verbrauch / Quota-Verschwendung).

### Sprache wählen

| Ordner | Sprache |
|--------|---------|
| [`de/`](de/) | Deutsch |
| [`en/`](en/) | English |

1. Dieses Paket kopieren (oder nur den benötigten Sprachordner).
2. Den AI-Coding-Agenten mit **`de/` oder `en/` als Arbeitsverzeichnis** öffnen
   (nicht diesen Root).
3. Die `README.md` in diesem Ordner befolgen und `Run STARTPROMPT.md` senden.

Die Checkliste ist am 2026-10-09 gegen die Provider-Changelogs geprüft
(`audit.yaml`, `schema_version: 2`). Ein Lauf schreibt keine Personen,
keine Projektnamen und keine absoluten Pfade in den Report.

`LICENSE` (CC0) gilt für das gesamte Paket.

## English

Clean-room package for a **read-only** first-pass audit of local AI coding
tools (token burn / quota waste).

### Choose a language

| Folder | Language |
|--------|----------|
| [`de/`](de/) | Deutsch |
| [`en/`](en/) | English |

1. Copy this package (or only the language folder you need).
2. Open your AI coding agent with **`de/` or `en/` as the working directory**
   (not this root).
3. Follow that folder’s `README.md` and send `Run STARTPROMPT.md`.

The checklist was reviewed on 2026-10-09 against the provider changelogs
(`audit.yaml`, `schema_version: 2`). A run does not put people, project
names, or absolute paths into the report.

`LICENSE` (CC0) applies to the whole package.
